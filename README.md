# Al-Mashawz Website

A multi-page frontend website developed for a non-profit organization as a collaborative project. The website consists of 10 pages divided among 5 team members, with each member responsible for developing specific sections of the website.

## Overview

The project was created to provide the non-profit organization with a structured and modern online presence. The website presents information about the organization, its activities, governance, solidarity initiatives, and other relevant content through a collection of dedicated pages.

The project was developed collaboratively, with the 10 pages distributed among 5 team members. Each member was responsible for implementing their assigned pages while maintaining consistency with the overall design and user experience.

## Technologies

* **HTML5** — Website structure and content
* **CSS3** — Layout, styling, and responsive design
* **JavaScript** — Frontend interactions and dynamic behavior

## Website Structure

The website contains **10 pages**, divided among **5 team members**, with each member responsible for a specific group of pages.

### Pages I Developed

I was responsible for developing the following pages:

* **Governance** — Page presenting information related to the organization's governance.
* **Solidarity** — Page presenting the organization's solidarity-related initiatives and information.
